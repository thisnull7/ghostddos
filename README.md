## 📖 About

GhostDDoS is a high-performance multi-vector network stress testing tool built with Node.js. It leverages hybrid attack methods including HTTP flooding, TCP SYN flood, and UDP amplification with worker thread parallelism for maximum throughput.

---

## ⚡ Features

| Feature | Description |
|---------|-------------|
| 🔴 **Hybrid Mode** | Simultaneous HTTP + TCP + UDP attack vectors |
| 🧵 **Multi-Threaded** | 24 worker threads with 100 concurrent loops each |
| 🎭 **IP Spoofing** | Random IP generation for X-Forwarded-For headers |
| 🔄 **User-Agent Rotation** | 5000+ user agents cycled randomly |
| 📦 **Jumbo Payloads** | Up to 65KB random payload per request |
| 🎯 **Interactive Input** | Clean CLI menu for target configuration |
| 📊 **Live Attack Log** | Real-time scrolling attack status display |
| 🛑 **Graceful Shutdown** | CTRL+C to safely terminate all threads |
